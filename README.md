# 교육 홈페이지 자동 생성기

한양대학교 백남학술정보관 이용자 교육의 **프로그램 및 강사 안내 → HY-LU 신청 연결(QR 자동 생성) → 홍보**까지 한 번에 제작하는 도구입니다.
매달 반복되던 "일정 취합 → 홈페이지 수정 → 신청 링크·QR 제작" 작업을 **입력 폼 하나**로 줄였습니다.

## 개요

### 1. AI 활용 반응형 웹페이지 기획 및 구현
- **목적**: 매월 반복되는 교육 운영 방식 자동화
- **성과**: 반응형 웹페이지 구축 — <https://paiknamaiworkshop.vercel.app/>
- **메뉴**: 프로그램 소개, 교육 내용 및 일정, 라인업, 굿즈 소개, 신청하기(HY-LU 연계)

### 2. 교육 운영 프로세스 One-Stop 자동화
- 교육 홍보부터 HY-LU 신청까지 **한 페이지에서 이어지는 One-Stop 서비스** 구현
- 월별 교육 일정 취합 → HY-LU 교육 개설 → 홍보물 제작으로 이어지는 **반복 업무 자동화**
- PC · 모바일 모두 지원하는 **반응형 웹**으로 이용자 접근성 향상

## 운영 성과

| 구분 | 내용 |
|---|---|
| 홍보물 제작기간 단축 | (기존) 약 3일 → **30분 이내** |
| 홍보물 제작비용 절감 | 배너 제작비용 **미발생** |
| 이용자 편의성 | 신청 접근성 증가 (홍보 페이지에서 HY-LU 신청까지 바로 연결) |

## 구성

- **`generator/`** — 홈페이지 자동 생성기 (브라우저에서 바로 실행, 설치 불필요)
  - `index.html` : 입력 폼 · 실시간 미리보기 · ZIP 내려받기 화면
  - `render.js` : 입력값 → 6개 페이지(HTML) + `sitemap.xml` · `robots.txt` · `vercel.json` 생성
  - `defaults.js` : 폼의 기본값 (현재 운영 중인 교육 내용)
  - `styles.js` : `site/styles.css` 의 사본 (단일 HTML 내보내기용 — `styles.css` 를 수정하면 함께 갱신)
- **`site/`** — 실제로 배포되는 사이트 폴더
  - `styles.css`, `vercel.json` : 고정 디자인 · 배포 설정 (매달 수정할 필요 없음)
  - `images/` : 포스터 · 로고 · 굿즈 사진 (파일 목록은 아래 참고)
- **`HISTORY.md`** — 개발 히스토리

## 주요 기능

- 교육 정보 입력만으로 **홈 · 프로그램 소개 · 교육 내용 및 일정 · 라인업 · 신청 · 굿즈** 6개 페이지 자동 생성
- **HY-LU 링크를 붙여 넣으면** 모든 "신청하기" 버튼이 연결되고 **신청 QR 이미지가 자동 생성**
- 회차 · 굿즈 · 경력 항목 추가/삭제/순서 변경, 접수 중 ↔ 마감 전환 (마감 시 신청 버튼 자동 숨김)
- **단일 HTML 파일 내보내기**: CSS · 이미지 · QR을 한 파일에 담아 메일 첨부, 드라이브, 학교 게시판 등에 바로 사용 (6개 페이지는 한 파일 안에서 메뉴로 전환)
- PC / 모바일 미리보기, 필수 항목 점검 목록
- 반응형 웹 (PC · 모바일), 검색 · SNS 공유용 메타태그와 사이트맵 자동 갱신
- 입력값을 `.json`으로 저장 · 불러오기 → 매달 이전 설정에서 시작

## 사용 방법 (매달)

1. `generator/index.html`을 브라우저(Chrome 권장)로 엽니다. *(QR 생성에 인터넷 연결 필요)*
2. 폼에서 **① 교육 기본 정보 → ② HY-LU 링크 → ③ 회차 · 일정**을 입력합니다. 나머지는 "펼치기"에서 필요할 때만 수정합니다.
3. 오른쪽 미리보기에서 6개 페이지를 확인합니다. 포스터 · 사진을 바꾸려면 해당 항목에서 파일을 올립니다.
4. **사이트 ZIP 내려받기**를 누르고, 압축을 풀어 `site/` 폴더에 덮어씁니다.
5. 배포합니다. (아래 참고)

### 단일 HTML 파일로 쓰기

폼의 **단일 HTML 파일 내려받기**를 누르면 `.html` 파일 하나가 만들어집니다. 서버나 `site/` 폴더 없이 더블클릭으로 열립니다.
기존 이미지를 파일 안에 넣으려면 먼저 **기존 이미지 폴더 불러오기**로 `site/images` 폴더를 한 번 선택하세요. (선택하지 않은 이미지는 파일에 포함되지 않습니다.)

> 새로 올린 이미지만 ZIP에 담깁니다. 올리지 않은 이미지는 `site/images/`의 기존 파일을 그대로 사용합니다.

## 배포 방법 (Vercel)

`site/` 폴더를 Vercel 프로젝트의 루트 디렉터리로 지정해 배포합니다.
GitHub 저장소와 연결해 두면 `site/` 변경을 push 할 때마다 자동으로 배포됩니다.

배포 주소가 정해지면 폼의 **세부 설정 → 사이트 공통 · 배포 주소**에 입력하세요.
(canonical, Open Graph, sitemap, robots에 반영됩니다.)
